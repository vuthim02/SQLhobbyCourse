# SQL Mega Course: Zero to Hero 🚀

A **comprehensive, free SQL/MySQL course** built from 4 of the best full-length SQL tutorials on YouTube. This course merges the strengths of multiple instructors into one structured, progressive learning path.

## 📺 Source Videos

This course is built around these 4 free YouTube courses:

| # | Course | Channel | Duration | Link |
|---|--------|---------|----------|------|
| 1 | SQL Course for Beginners | Programming with Mosh | ~4h | [Watch](https://youtu.be/7S_tz1z_5bA) |
| 2 | SQL Full Course for free 🐬 | Bro Code | ~4h | [Watch](https://youtu.be/5OdVJbNCSso) |
| 3 | SQL Tutorial - Full Database Course for Beginners | freeCodeCamp (Brototype) | ~4h | [Watch](https://youtu.be/HXV3zeQKqGY) |
| 4 | Harvard CS50's Intro to Databases with SQL | freeCodeCamp (CS50) | ~12h | [Watch](https://youtu.be/WXk7yDqsKxs) |

**Total Video Content: ~24 hours**

## 🎯 Who Is This For?

- **Complete beginners** with zero database knowledge
- Self-learners who want a **structured path** through free video content
- Anyone who wants **notes, exercises, and projects** to reinforce video learning
- Students preparing for **database/SQL interviews**

## 📚 Course Structure

This course is organized into **6 weeks** of progressive learning:

| Week | Topics | Primary Source(s) |
|------|--------|-------------------|
| **1** | SQL Basics: SELECT, WHERE, ORDER BY, LIMIT | Mosh + Bro Code |
| **2** | Data Manipulation: INSERT, UPDATE, DELETE, Data Types, Constraints | Bro Code + Brototype |
| **3** | Joins, Aggregations, Subqueries, String/Date Functions | Brototype + CS50 |
| **4** | Advanced SQL: Indexes, Transactions, Views, Triggers, Stored Procedures | CS50 |
| **5** | Database Design: ER Diagrams, Normalization, Relational Algebra | CS50 |
| **6** | Real-World: Security, Performance Tuning, APIs & Databases | CS50 + All |

Each week includes:
- 📖 **Lesson files** (`lesson-XX-topic.md`) — written notes + examples
- 💻 **Exercises** (`exercises.sql`) — hands-on practice queries
- 🎬 **Video timestamps** — exact moments to watch in each source video

## 🚀 How to Use This Course

### Step 1: Set Up MySQL

If you haven't installed MySQL yet, see the setup guide in the parent directory:
`../tools/setup.md`

### Step 2: Follow the Study Plan

Open [`STUDY-PLAN.md`](./STUDY-PLAN.md) for a day-by-day schedule. Each week includes:
- **Watch** the relevant video sections (timestamps in each lesson)
- **Read** the lesson files for written explanations + examples
- **Practice** with the exercises.sql files
- **Build** the weekly project

### Step 3: Do the Projects

After completing the weeks, build the capstone projects in the `projects/` folder. These test everything you've learned.

### Step 4: Prepare for Interviews

Use the [`interview-prep/questions.sql`](../interview-prep/questions.sql) in the parent directory to practice common SQL interview questions.

- A computer with **MySQL 8.0+** installed

- **No prior SQL/database knowledge** required

## 📝 Learning Approach

This course follows the **Watch → Read → Practice → Build** method:

1. **Watch** the video sections (visual + auditory learning)
2. **Read** the lesson notes (reinforcement + reference)
3. **Practice** with exercises (hands-on repetition)
4. **Build** projects (real-world application)
